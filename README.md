# Projeto Forte — site inicial de afiliados

Site estático em HTML, CSS e JavaScript. Não usa banco de dados, não exige instalação de dependências e pode ser hospedado em serviços estáticos.

## Arquivos
- `index.html`: página inicial com catálogo inicial de cinco produtos e links de afiliado fornecidos pelo proprietário.
- `styles.css`: identidade visual preta e dourada, responsiva.
- `script.js`: menu móvel e ano automático.
- `guias/`: três artigos iniciais.
- `aviso-de-afiliados.html`: aviso de transparência.
- `politica-de-privacidade.html`: política inicial para revisar.
- `contato.html`: página de contato com campo para substituir.

## Antes de publicar
1. Confirme o nome da marca e verifique disponibilidade de domínio e marca.
2. Troque `SEU_EMAIL_AQUI` pelo seu contato real.
3. Coloque links dos seus perfis públicos cadastrados no programa.
4. A página inicial já contém cinco links de afiliado fornecidos pelo proprietário. Teste cada botão publicado. Os espaços reservados nos artigos ainda precisam ser substituídos por links reais antes de afirmar que esses artigos recomendam os mesmos produtos.
5. Atualize preços e especificações manualmente antes de publicar qualquer comparação.
6. Cadastre o site nos canais do Programa de Afiliados do Mercado Livre e confirme as regras vigentes.
7. Mantenha a identificação de publicidade/afiliado clara.
8. Não promova links em canais não permitidos. As orientações oficiais atuais do Mercado Livre informam restrições para buscadores, SEO, anúncios de busca, grupos privados, sites não cadastrados e links encurtados externos. Verifique os termos oficiais mais recentes antes de divulgar.
9. Revise a política de privacidade de acordo com a hospedagem e ferramentas que realmente instalar.

## Publicar grátis
### GitHub Pages
1. Crie uma conta no GitHub, se necessário.
2. Crie um repositório público, por exemplo `projeto-forte`.
3. Envie todos os arquivos mantendo a estrutura de pastas.
4. Nas configurações do repositório, habilite Pages para publicar a partir do branch principal (`main`) e da raiz (`/`).
5. Use a URL que o GitHub fornecer e teste no celular e no computador.

### Vercel
1. Envie os arquivos para um repositório GitHub.
2. Importe o repositório no Vercel.
3. Para este site estático, não é necessário build command; o diretório de saída é a raiz.
4. Publique e teste as páginas e links.

## Estratégia de tráfego
Use o site como destino de conteúdos publicados em perfis públicos permitidos e cadastrados. Não planeje tráfego por buscadores até confirmar que os termos do programa permitem isso — as orientações oficiais consultadas atualmente proíbem divulgação em buscadores, inclusive SEO e anúncios de busca.

## Nota
O nome “Projeto Forte” é provisório. O site é um modelo inicial, não uma integração automática com o Mercado Livre. Os produtos, preços, comissões e links precisam ser inseridos e verificados pelo afiliado.
